01 / WHY HARDWARE?

A computer can
lose its software
way in.

Remote desktop and SSH depend on services running inside the target machine. Some tasks begin before those services exist.

SRC explores another path: capture the display through PiKVM and deliver keyboard and mouse actions through USB. The interaction happens at the computer’s physical interfaces.

This creates a foundation for supervised administration, boot-screen inspection, and lab experiments. Actual behaviour depends on the connected hardware, configuration, and target system.

02 / THE CONTROL PATH

Observe. Decide.
Act. Check.

A small set of components separates the operator interface from the hardware connection. Screenshots travel back; input commands travel forward.

  1. 01 / INTENT

    Operator or MCP client

    A person directs the task through the Operator UI or a connected MCP client.

  2. 02 / BOUNDARY

    Local HTTP bridge

    The bridge handles authentication, input validation, request limits, and audit records.

  3. 03 / INTERFACE

    PiKVM + target

    PiKVM provides screen capture and USB keyboard/mouse interaction with the target computer.

The target can be network-isolated. The controller still needs access to PiKVM and, when using the Operator UI, the configured OpenAI service.

05 / GOOD QUESTIONS

A little more
context.

For technical setup, the repository is the source of truth.

Does SRC install software on the target computer?

The control path uses PiKVM video capture and USB keyboard/mouse input rather than an OS-level agent on the target. The controller runs the bridge and its clients.

Does it work entirely offline?

Not in the current Operator UI configuration. The target can be network-isolated, but the controller needs access to PiKVM and OpenAI. Task text and screenshots are sent to the configured OpenAI service.

What does “supervised” mean?

A person directs and monitors the work. Stop cancels pending work; input already dispatched may still take effect. Optional power actions must be deliberately enabled.

Is the demo connected to a live device?

No. The website demo is a simulator that illustrates the interaction. It does not demonstrate a live hardware connection or measured performance.

Can I buy or evaluate SRC?

SRC is in development. Contact LabXIII to discuss your evaluation needs or explore the public source. An enquiry is not an order, allocation, or shipping commitment.
